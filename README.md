# FlashcardQuiz
This Flashcard Quiz App is a simple Android application developed in Kotlin that helps users test their knowledge using true-or-false questions. The app begins with a welcome screen, guiding users to a series of five flashcard questions. Users respond by selecting "True" or "False," and immediate feedback is provided for each answer. After completing the quiz, the app displays the user's score along with personalized feedback. Users can then review all the questions with correct answers or exit the app. The app combines interactive learning with a clean, user-friendly interface to make studying more engaging.
